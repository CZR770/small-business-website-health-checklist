## First ten checks

- [ ] Critical forms tested and confirmations actually received
- [ ] Page title and search description are descriptive
- [ ] Phone menu, calls to action and inputs work
- [ ] Important pages can be inspected in Search Console
- [ ] No accidental `noindex`, broken canonical or blocked priority path
- [ ] Internal navigation works; redirects are sensible
- [ ] Headings communicate the page's purpose
- [ ] Meaningful images have appropriate alternatives
- [ ] Browser performance checked separately from static source checks
- [ ] Contact, terms, and privacy links are accurate and accessible
